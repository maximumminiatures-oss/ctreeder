# Source and asset provenance

This repository combines the owner's initial `ctreeder` repository with the
ShadowSpawner project history and the actual public files served by ctreeder.com.

- Original project: https://github.com/ShadowDarklings/SD-Dungeon-Generator
- Live source at migration: `65eb5f2a77fb3b0bd1dc725ad8c0f7a49817c8b6`.
- Imported development history: `bebe7a9c56e40eb6948e2450c946aa41a984e729`.
- Original authorship/history are retained. Contributors include Charles Reeder
  (`maximumminiatures-oss`), `mrod440`, Megan Gwirtz, and commits under the
  shared `Ubuntu` author identity.
- Test/CI fixes originated in group PR #25 and are included here independently
  of whether the group repository merges that PR.
- `portfolio/` was exported from the live public document root on 2026-09-24.
  It includes the portfolio, illustrations, world map, MCC generator, images,
  styles, scripts, and code samples.
- The owner's initial `LICENSE` is retained. Existing third-party notices and
  asset attribution remain with their files; migration does not replace those
  notices or assign ownership of third-party material.

No private production database content, authentication secrets, or TLS keys
are included. Historical AWS/group links are not runtime dependencies.
